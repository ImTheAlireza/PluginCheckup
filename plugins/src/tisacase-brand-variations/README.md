# 🧩 TisaCase — گروه‌بندی متغیرها بر اساس برند

> **نسخهٔ ۱٫۱٫۰** · افزونهٔ دوازدهم مجموعهٔ TisaCase · فقط نمایش سمت کاربر، بدون هیچ نوشتنی در محصولات.

صفحهٔ محصول `TS184` الان **۱۵۴ مدل** را در یک دراپ‌داون تخت نشان می‌دهد:
`iPhone 6 … iPhone 18 Pro Max, A03s … A73, S20 FE … S26 Ultra, Redmi Note 8 … Poco F6 Pro`.

این افزونه همان لیست را چنین می‌کند:

```
● آیفون                    ۳۸
  [ iPhone 6 ] [ iPhone 6s ] [ iPhone 6 Plus ] …
────────────────────────────────────────────
● سامسونگ                  ۶۴
  [ A03s ] [ A04s ] … [ S26 Ultra ]
────────────────────────────────────────────
● شیائومی                  ۵۲
  [ Redmi Note 8 ] … [ Poco F6 Pro ]
```

به‌همراه **جعبهٔ جستجو** (`a55` → یک نتیجه)، **خط جداکننده**، **رنگ برند** و **سواچ رنگ** برای ویژگی «رنگ».
هیچ محصول، متغیر، ویژگی یا متایی نوشته/تغییر نمی‌کند — همه‌چیز فقط در HTML سمت کاربر.

---

## ۱) نصب

```
پیشخوان › افزونه‌ها › افزودن افزونه › بارگذاری افزونه › tisacase-brand-variations.zip › فعال‌سازی
```

یا `wp plugin install tisacase-brand-variations.zip --activate`.
صفحهٔ تنظیمات: **ووکامرس › گروه‌بندی متغیرها** (و کارت آن در هاب تیساکیس).

پیش‌نیاز: ووکامرس فعال، PHP 7.4+، وردپرس 5.8+.

**بعد از فعال‌سازی هیچ‌جای فروشگاه عوض نمی‌شود** — چون «حالت تست» از اول روشن است.
بروید سراغ کارت «حالت تست» در بالای صفحهٔ تنظیمات، ۱ تا ۲ محصول را اضافه کنید و ذخیره کنید؛
فقط همان محصول‌ها گروه‌بندی می‌شوند. هر وقت راضی بودید، دکمهٔ «روشن‌کردن برای کل فروشگاه».

---

## ۲) حالت تست (پیش‌فرض: روشن)

بالای صفحهٔ تنظیمات، قبل از تب‌ها:

```
┌─ تست ────────────────────────────────────────────── [روشن — فقط ۲ محصول زیر] ─┐
│  (●) حالت تست                 [x] نشان «حالت تست» روی صفحهٔ محصول (فقط مدیر)   │
│                                              [روشن‌کردن برای کل فروشگاه]      │
│  [ نام محصول آزمایشی (مثلاً قاب TS184)… ]  [جستجوی محصول]                     │
│  ( قاب اسپیس کد TS184  #271672  مشاهده  × ) ( قاب TS337  #271900  مشاهده  × ) │
└──────────────────────────────────────────────────────────────────────────────┘
```

- تا وقتی حالت تست روشن است، **هیچ محصول دیگری** در فروشگاه تغییر نمی‌کند — نه پنل سمت کاربر، نه `<optgroup>` سرور، نه بارگذاری CSS/JS (فایل‌ها فقط در همان صفحه‌های انتخابی صادر می‌شوند).
- اگر حالت تست روشن باشد و هیچ محصولی انتخاب نکرده باشید، افزونه عملاً **خاموش** است (پنل مدیریت یک هشدار زرد نشان می‌دهد).
- حداقل ۱ و حداکثر ۲۰ محصول؛ چیپ هر محصول دکمهٔ «مشاهده» (باز کردن همان صفحه) و «×» (حذف) دارد.
- «نشان حالت تست» یک نوار کوچک بالای فرم متغیرها است که **فقط مدیر** آن را می‌بیند؛ برای بازدیدکنندهٔ عادی هیچ خروجی‌ای ندارد.
- در همین حال، پیش‌نمایش زنده و تحلیلگر پنل با مدل‌های واقعی کار می‌کنند تا قواعد را بدون دست‌زدن به سایت تنظیم کنید.

> برای پوشش کل فروشگاه: تیک «حالت تست» را بردارید (یا دکمهٔ «روشن‌کردن برای کل فروشگاه» را بزنید) و ذخیره کنید.
> بعد از آن، تب پیشرفته › «دامنهٔ محصولات» تعیین می‌کند روی همه باشد یا فقط دسته‌های خاص.

## ۳) چهار تب

| تب | چه‌کاری می‌کند |
|----|----------------|
| **برندها** | ردیف‌های برند: نام، رنگ، آیکن/ایموجی، کلیدواژه‌ها، الگوی regex، فهرست دستی مدل‌ها، فعال/غیرفعال و ترتیب (▲▼). ترتیب ردیف = ترتیب نمایش در سایت = اولویت تطبیق. |
| **نمایش** | حالت نمایش (پنل/فقط‌مرتب‌سازی/خاموش)، چیدمان (چیپ/لیست/دو‌ستونه)، شکل جداکننده، ترتیب مدل‌ها، ارتفاع پنل، جستجو، شمارش، عنوان چسبان، چیپ فیلتر برند، اعداد فارسی و وضعیت مدل‌های ناموجود. |
| **رنگ‌ها** | رنگ‌بندی کامل پنل (۱۱ رنگ)، گردی گوشه، اندازهٔ قلم، سایه، و تنظیمات سواچ «رنگ» + نقشهٔ نام‌رنگ → کد رنگ. |
| **پیشرفته** | دامنهٔ تشخیص ویژگی‌ها، آستانه‌ها، ویژگی‌های مستثنا، دامنهٔ محصولات (همه/فقط دسته‌ها/همه جز دسته‌ها)، حالت ایمن، خروجی/بازیابی JSON و بازنشانی. |

در کنار همهٔ تب‌ها یک **پیش‌نمایش زنده** هست که با همان CSS/JS صفحهٔ محصول ساخته می‌شود؛ با تغییر رنگ یا چیدمان، همان لحظه به‌روز می‌شود و می‌توانید پیش‌نمایش را با **مدل‌های واقعی یکی از محصولات** خودتان ببینید.

## ۴) تحلیلگر مدل‌ها (مهم‌ترین ابزار)

در تب «برندها»، دکمهٔ **بارگذاری مدل‌های یک محصول…** → جست‌وجوی نام محصول → انتخاب → لیست واقعی مدل‌ها در کادر تحلیل می‌آید.

نتیجه: هر برند با تعداد و همهٔ مدل‌هایش + فهرست **ناشناس‌ها** و **تضادها** (مدلی که با دو برند می‌خواند).
روی هر مدل ناشناس یک `+` هست؛ برند را از دراپ‌داون همان سطر انتخاب کنید و `+` را بزنید تا آن مدل به «فهرست دستی» آن برند اضافه شود (ذخیره‌شدنی). دکمهٔ «افزودن همه…» هم کل گروه ناشناس‌ها را می‌چسباند.

## ۵) قواعد پیش‌فرض (روی ۱۵۴ مدل واقعی آزمون‌شده)

| برند | کلیدواژه‌ها | الگو (regex) |
|------|--------------|--------------|
| آیفون | `iphone` `ipad` `ipod` `apple` `آیفون` `اپل` | — |
| سامسونگ | `galaxy` `samsung` `سامسونگ` `گلکسی` | `^(?:galaxy[\s\-]*)?(?:[asmjz]\s?\d{1,2}[a-z]{0,3}|z\s?(?:flip|fold)\s?\d?)(?:\s.*)?$` |
| شیائومی | `redmi` `poco` `mi` `xiaomi` `ردمی` `پوکو` `شیائومی` | — |

نتیجه روی لیست واقعی TS184: **۳۸ آیفون · ۶۴ سامسونگ · ۵۲ شیائومی · ۰ ناشناس · ۰ تضاد** (۱۵۴ = ۱۵۴).

سه نکته که چرا این قواعد کار می‌کنند:

1. **نرمال‌سازی**: نیم‌فاصله، فاصلهٔ مجازی، `ي/ى/ی`، `ك/ک`، اعراب، ارقام فارسی/عربی و بزرگی/کوچکی حروف — قبل از هر مقایسه یکدست می‌شوند (هم در PHP هم در JS).
2. **تطبیق کلمه‌ای**: کلیدواژهٔ `mi` فقط روی کلمهٔ مستقل «Mi» می‌خورد، پس `M31` یا `Mini` را اشتباه نمی‌گیرد؛ و `A5` (سامسونگ) از `Redmi A5` جدا می‌ماند چون آن مقدار با `redmi` اولویت می‌گیرد.
3. **فهرست دستی برندهٔ نهایی**: هر مدلی که در فهرست دستی یک برند باشد، همهٔ قواعد را باطل می‌کند.

با دکمهٔ «افزودن برند آماده» این‌ها هم با یک کلیک اضافه می‌شوند:
هواوی/آنر، گوگل پیکسل، نوکیا، اوپو، ریلمی، وان‌پلاس، ناتینگ، سونی، موتورولا، ایسوس، تکنو/اینفینیکس، آیپد/تبلت، غیر‌موبایل.

## ۶) سواچ رنگ

ویژگی‌هایی که نامشان رنگ/color/رنگ‌بندی است (قابل تغییر در تب پیشرفته) به‌جای دراپ‌داون، **سواچ رنگی** می‌شوند:
`صورتی` → نقطه‌ی `#FF7EB6`، `آبی` → `#2F80ED` … و برای نام‌های ترکیبی هوشمند است:
«مشکی روشن» → تیره‌تر و روشن‌تر شدهٔ `#111111`، «طرح‌دار» → `@multi` (گرادیان)، «شفاف» → `@clear` (شطرنجی)، نام ناشناس → رنگ فالبک.

دکمهٔ «افزودن رنگ‌های پرکاربرد فارسی» بیش از ۵۰ نام رنگ فارسی/انگلیسی را به نقشه اضافه می‌کند. نقشه در هر خط `نام: کد` نوشته می‌شود.

## ۷) چطور مطمئن شویم چیزی خراب نمی‌شود؟

- **select اصلی ووکامرس پاک نمی‌شود**: با کلاس `tcbv-native` فقط از دید پنهان می‌شود (۱×۱ پیکسل). همهٔ منطق قیمت/تصویر/موجودی/سبد ووکامرس و قالب، مثل قبل روی همان select کار می‌کند و پنل ما فقط مقدارش را ست و رویداد `change` را شلیک می‌کند.
- **بدون جاوااسکریپت هم مرتب است**: سرور همان گروه‌بندی را با `<optgroup>` می‌سازد (قابل دیدن در حالت «فقط مرتب‌سازی» یا با JS خاموش).
- **حالت ایمن**: تیک تب پیشرفته → پنل جستجو کلاً خاموش، فقط مرتب‌سازی سرور.
- **گروه‌بندی قبلی قالب محترم است**: اگر قالب/افزونهٔ دیگری از قبل `<optgroup>` گذاشته باشد، دست نمی‌زنیم.
- **دامنهٔ محصولات**: می‌شود افزونه را فقط برای دسته‌های خاص روشن کرد.
- **حالت تست**: تا روشن است، فقط محصول‌های انتخابی شما دیده می‌شوند و بقیهٔ فروشگاه کاملاً دست‌نخورده است (همان دامنه‌ای که در سرور هم اعمال می‌شود).
- **حذف افزونه**: هیچ داده‌ای در محصولات نیست؛ فقط یک آپشن تنظیمات که پیش‌فرض پاک نمی‌شود (اگر بخواهید، تیک تب پیشرفته).

فیلترهای توسعه‌دهنده:

```php
add_filter( 'tcbv_load', fn( $load, $product_id ) => $product_id !== 123, 10, 2 ); // خاموش‌کردن برای یک محصول
add_filter( 'tcbv_should_group', fn( $yes, $attr, $values, $settings ) => $yes, 10, 4 );
add_filter( 'tcbv_is_color_attr', fn( $yes ) => $yes );
```

## ۸) ساختار فایل‌ها

```
tisacase-brand-variations.php        بوت، ثابت‌ها، ثبت در هاب
includes/class-tcbv-settings.php     تنظیمات، پیش‌فرض‌ها، پاک‌سازی، برندهای آماده
includes/class-tcbv-rules.php        موتور تشخیص (نرمال‌سازی، تطبیق، گروه‌بندی، تضاد)
includes/class-tcbv-frontend.php     enqueue + فیلتر دراپ‌داون ووکامرس (optgroup سرور)
includes/class-tcbv-admin.php        پنل ۴تبی + AJAX (محصولات، ویژگی‌ها، تحلیل)
assets/frontend.(js|css)             پنل جستجوپذیر و سواچ (بدون jQuery، بدون CDN)
assets/admin.(js|css)                پنل مدیریت + پیش‌نمایش زنده
uninstall.php                        حذف آپشن (اختیاری)
```

پیش‌نمایش بدون وردپرس: `design/preview/brand-variations.html` (همان CSS/JS افزونه با ۱۵۴ مدل واقعی).

## ۹) چک‌لیست تست روی سایت

0. کارت «حالت تست» → محصول آزمایشی (مثلاً `قاب اسپیس کد TS184`) را اضافه و ذخیره کنید؛ یک محصول متغیر *دیگر* را باز کنید و مطمئن شوید هیچ تغییری ندارد (نه گروه‌بندی، نه خط جداکننده).
1. همان محصول آزمایشی (`قاب اسپیس کد TS184`) را باز کنید.
2. سه گروه با عنوان، شمارش و دو خط جداکننده ببینید؛ آیفون بالای فهرست باشد.
3. یک مدل انتخاب کنید → قیمت/تصویر/موجودی ووکامرس همان‌طور که قبلاً بود به‌روز شود.
4. «افزودن به سبد خرید» کار کند و در سبد همان مدل ثبت شود.
5. «صورتی/آبی» به‌شکل نقطه‌ی رنگی نمایش داده شود و انتخابش کار کند.
6. در پنل، رنگ تأکید را عوض کنید → پیش‌نمایش زنده تغییر کند و بعد از ذخیره، صفحهٔ محصول هم.
7. تب برندها → «بارگذاری مدل‌های یک محصول…» → تعدادها و ناشناس‌ها را ببینید.
8. بالای فرم متغیرها نوار زرد «حالت تست» را ببینید (فقط وقتی با حساب مدیر وارد شده‌اید) و در همان صفحه، یک ناشناس/بازدیدکنندهٔ عادی (Incognito) آن نوار را نبیند.
9. وقتی راضی بودید: «روشن‌کردن برای کل فروشگاه» → صفحهٔ دو سه محصول دیگر را هم چک کنید.
