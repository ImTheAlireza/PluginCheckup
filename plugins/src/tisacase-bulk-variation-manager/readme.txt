مدیریت و تولید انبوه متغیرها، مدل‌های گوشی و ویژگی‌های محصولات ووکامرس برای قاب‌های اسپیس و چاپی تیساکیس.

== Description ==

افزونه اختصاصی تیساکیس برای بازسازی و تولید گروهی متغیرها از صفر بر اساس نام ویژگی، مقادیر جدید و اعمال یکپارچه قیمت واردشده.

== Installation ==

1. Upload the plugin folder to the `/wp-content/plugins/` directory, or upload the zip via WordPress admin.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Access the plugin via WooCommerce -> Products -> TisaCase Variation Manager, or via TisaCase Hub menu.

== Changelog ==

= 2.0.2 =
* ابزار جدید «پاکسازی ویژگی از محصولات» (تب تازه): عنوان یک ویژگی را وارد کنید تا همهٔ محصولات دارای آن — هم ویژگی سراسری و هم محلی — جستجو و لیست شوند؛ سپس با تایید شما آن ویژگی به‌همراه متغیرهای وابسته‌اش از محصولات حذف می‌شود. مناسب برای پاکسازی ویژگی‌های اشتباه ساخته‌شده (مثل تایپ «مدل گوشی» به‌جای «مدل»).
* هر پاکسازی قبل از اجرا از محصولات اسنپ‌شات می‌گیرد و نتیجه در تب «تاریخچه» با قابلیت بازگردانی (Rollback) ثبت می‌شود؛ متغیرهای حذف‌شده با Rollback بازسازی می‌گردند.
* گزینهٔ اختیاری «حذف سراسری تعریف ویژگی»: پس از پاکسازی محصولات می‌توان تعریف تاکسونومی ویژگی و تمام ترم‌هایش را یک‌جا از فروشگاه پاک کرد (با تایید جداگانه و سقف ایمنی ۵۰۰۰ ترم) — این بخش مستثناً قابل Rollback نیست.
* پیش‌فرض چک‌باکس «ترکیب با سایر ویژگی‌ها» خاموش شد (مطابق رفتار مستند نسخهٔ ۱.۱.۱: دقیقاً یک متغیر به‌ازای هر مقدار) تا انفجار دکارتی — مثل ترکیب‌های ۲۳٬۷۱۶تایی — فقط در صورت انتخاب آگاهانه کاربر رخ دهد.

= 2.0.1 =
* رفع محدودیت ۱۰۰تایی لیست انتخاب: پیش‌تر از میان محصولات یافت‌شده (مثلاً ۳۰۰ قاب) فقط ۱۰۰ تای نخست به لیست انتخاب اضافه می‌شد، چون پاسخ جستجو فقط جزئیات ۱۰۰ محصول اول را برمی‌گرداند و باقی شناسه‌ها نادیده گرفته می‌شد.
* حالا همهٔ شناسه‌های یافت‌شده بلافاصله در لیست انتخاب ثبت می‌شوند؛ جزئیات محصولات بعد از ۱۰۰ تای اول به‌صورت تدریجی و در پس‌زمینه (بسته‌های ۱۰۰تایی از مسیر AJAX تازهٔ `tcbvm_products_summary_page`) تکمیل می‌شود.
* اجرا (Run) حتی پیش از تکمیل بارگذاری جزئیات، تمام شناسه‌های انتخاب‌شده را پوشش می‌دهد؛ وضعیت تیک/حذف کاربر در حین تکمیل خودکار لیست حفظ می‌شود.
* شمارندهٔ جستجو هنگام تکمیل لیست پیشرفت بارگذاری جزئیات را نمایش می‌دهد.

= 2.0.0 =
* بازنویسی و بازسازی کامل افزونه از صفر بر اساس جریان کار اختصاصی:
  ۱. انتخاب محصولات با دسته‌بندی، جستجوی مستقیم یا شناسه‌ها + جدول زنده انتخاب.
  ۲. تعیین نام ویژگی (مثل «مدل گوشی») و تعریف لیست متغیرهای جدید با پشتیبانی از خطوط و پایپ (|).
  ۳. تولید و بازسازی متغیرها از ابتدا با محاسبه دقیق ضرب دکارتی و ترکیب درست سایر ویژگی‌ها.
  ۴. اعمال یکپارچه قیمت واردشده روی تمام متغیرهای جنریت‌شده.
  ۵. پیش‌نمایش دقیق تغییرات پیش از اجرا + پردازش پله‌ای ایجکس با نوار پیشرفت و لاگ زنده.
  ۶. پشتیبان‌گیری خودکار (Snapshot) و بازگردانی با یک کلیک (Rollback).
  ۷. تطبیق کامل با زبان طراحی TisaCase UI (توکن‌ها، بدون رنگ یا ابعاد هاردکد).

* سایر ویژگی‌های متغیر در حالت «یک متغیر به‌ازای هر مدل» از محصول برداشته می‌شوند (ترم‌ها و داده‌هایشان حذف نمی‌شوند و با بازگردانی برمی‌گردند) تا ووکامرس منتظر مقدار آن‌ها نماند.
* گزینهٔ جدید «حفظ سایر ویژگی‌های متغیر (ساخت ترکیبی)» — پیش‌فرض خاموش — برای محصول‌هایی که واقعاً چند ویژگی متغیر دارند.
* تنظیمات نمایش ویژگی (نمایان بودن و ترتیب) پس از بازسازی حفظ می‌شود.

* بازگردانی (Rollback) حالا متغیرهای حذف‌شده را از اسنپ‌شات دوباره می‌سازد (SKU اصلی فقط اگر آزاد باشد).
* همچنان: بدون هیچ ساخت/تغییر SKU، بدون ساخت محصول جدید.

* رفع خطای «Network timeout on batch» در اجرای عملیات گروهی:
  • ذخیرهٔ تاریخچه/اسنپ‌شات‌ها: قبلاً برای هر متغیر و هر محصول، کل آپشن تاریخچه دوباره خوانده و بازنویسی می‌شد (کندی شدید + ریسک تایم‌اوت و کمبود حافظه). حالا یک‌بار در هر درخواست خوانده و در پایان بسته ذخیره می‌شود.

  • خطای یک محصول دیگر کل بسته را از کار نمی‌اندازد (try/catch روی هر محصول) و پیام خطا در لاگ نمایش داده می‌شود.

  • تلاش مجدد هوشمند در سمت مرورگر: اگر بسته‌ای شکست بخورد، به دو نیم تقسیم و دوباره تلاش می‌شود (تا تک‌محصولی) و اجرا با بقیهٔ محصولات ادامه می‌یابد؛ پیام خطا حالا کد HTTP و متن پاسخ سرور را نشان می‌دهد.
