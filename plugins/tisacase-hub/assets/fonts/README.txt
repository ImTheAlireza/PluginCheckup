Vazirmatn — محلی‌سازی قلم (اختیاری ولی توصیه‌شده)
===============================================

اگر فایل‌های woff2 را همین‌جا بگذارید، هاب خودش @font-face می‌سازد؛ هیچ تنظیمی
لازم نیست و فایل tisacase-ui.css را هم نباید دست بزنید.

نام‌گذاری (وزن داخل اسم فایل بخواند):

    vazirmatn-400.woff2
    vazirmatn-500.woff2
    vazirmatn-600.woff2
    vazirmatn-700.woff2
    vazirmatn-800.woff2

وزن‌های ۴۰۰ تا ۸۰۰ در زبان طراحی استفاده می‌شوند. برای ایتالیک (کمتر لازم است):
    vazirmatn-400-italic.woff2

منابع: releases رسمی روی GitHub — نسخهٔ «Variable» هم کار می‌کند اگر اسمش را
vazirmatn-400.woff2 بگذارید (وزن متغیر، همهٔ وزن‌ها را پوشش می‌دهد).

چرا لازم است؟ افزونهٔ case-special-package قلم را از CDN گوگل می‌گیرد؛ داخل ایران
هم کند است و هم فونت می‌پرد. این پوشه همان دردسر را برای همهٔ ۹ افزونه حل می‌کند.
بدون این فایل‌ها هم چیزی خراب نیست: از قلم سیستم استفاده می‌شود.
